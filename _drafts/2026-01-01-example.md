## Table of Contents

To add a table of contents, define a `toc` section in your front matter. For example, this post uses:

```yaml
toc:
  - name: Introduction
  - name: Table of Contents
  - name: Images with Captions
    subsections:
      - name: Basic Image
      - name: Full-Width Image
  - name: Footnotes
  - name: Asides
  - name: Citations
  - name: Math Examples
  - name: Conclusion
```

The TOC will automatically appear on the left side of your article and help readers navigate through longer posts.

## Images with Captions

### Basic Image

To add an image that aligns with the text width and includes a caption, use the HTML `<figure>` element:

```html

  <figcaption>Figure 1: The CLeaR Group logo.</figcaption>
</figure>
```

### Full-Width Image

For images that span the full width of the page, use the `l-page` class:

```html
<figure class="l-page">
  <img src="..." alt="..." style="width: 100%;">
  <figcaption>Your caption here.</figcaption>
</figure>
```

<figure class="l-page">
  <img src="/dietrich/causality/assets/img/blogs/2026-01-01-example/clear.png" alt="CLeaR Group Logo Full Width" style="width: 100%;">
  <figcaption>Figure 2: A full-width image using the <code>l-page</code> class. This extends beyond the text column for more impactful visuals.</figcaption>
</figure>

You can also use `l-body` for standard width or `l-body-outset` for slightly wider than text:

```html
<figure class="l-body-outset">
  <img src="..." alt="..." style="width: 100%;">
  <figcaption>Your caption here.</figcaption>
</figure>
```

</figure>

## Footnotes

Footnotes in Distill are created using the `<d-footnote>` tag. They appear as hoverable superscript numbers<d-footnote>Like this! Footnotes are great for providing additional context, references, or tangential information without cluttering the main text.</d-footnote> and are collected at the bottom of the article.

Here's how to write a footnote in your markdown:

```html
Some text<d-footnote>Your footnote content here.</d-footnote> continues here.
```

You can include multiple footnotes<d-footnote>This is another footnote demonstrating that you can have as many as needed.</d-footnote> throughout your article.

## Asides

Asides are marginal notes that appear alongside your main content. They're perfect for:

<strong>Pro tip:</strong> Use asides sparingly to highlight important supplementary information without interrupting the reader's flow.

- Providing additional context
- Highlighting key definitions
- Adding commentary
- Showing related examples

To create an aside, use the `<aside>` HTML tag:

```html
<aside>
Your marginal note content here.
</aside>
```

<aside>
Asides work best when they're positioned near the relevant text they're commenting on.

## Citations

Distill supports academic citations using the `<d-cite>` tag. You need to:

1. Create a bibliography file (e.g., `2026-01-01-example.bib`) in `assets/bibliography/`
2. Reference it in your front matter with `bibliography: 2026-01-01-example.bib`
3. Cite papers using their BibTeX keys

For example, cite work on causal and anticausal learning<d-cite key="schoelkopf2012causal"></d-cite>. You can also cite multiple papers at once<d-cite key="schoelkopf2012causal,pearl2009causality"></d-cite>.

The syntax is simple:

```html
Some claim<d-cite key="bibtex_key"></d-cite>.
Multiple citations<d-cite key="key1,key2,key3"></d-cite>.
```

## Math Examples

Distill supports $$ \LaTeX $$ math rendering. Both inline and block math use double dollar signs (`$$`), with the difference being line placement:

- **Inline math**: Place `$$...$$` on the same line as surrounding text, e.g., `$$E = mc^2$$` renders as $$E = mc^2$$
- **Block math**: Place `$$` on its own line, then the equation, then `$$` on its own line

Block math example:

```markdown
$$
\mathcal{L}(\theta) = -\sum_{i=1}^{n} \log p(x_i | \theta)
$$
```

$$
\mathcal{L}(\theta) = -\sum_{i=1}^{n} \log p(x_i | \theta)
$$

## Conclusion

This post covered the essential features of writing Distill-style blog posts:

- **Table of Contents**: Define in front matter for easy navigation
- **Images**: Use `<figure>` with `<figcaption>` for captioned images
- **Footnotes**: Use `<d-footnote>` for inline notes
- **Asides**: Use `<aside>` for marginal notes
- **Citations**: Use `<d-cite>` with a bibliography file
- **Math**: Use `$$...$$` for both inline and block; block uses newlines
